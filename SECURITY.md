## Reporting Security Issues

If you discover a vulnerability or security concern, report it directly to NICTOLabs:

- Do not open a public issue for security vulnerabilities
- Email: security@nictolabs.com
- Include a clear description, reproduction steps, and potential impact
- Allow adequate time for NICTOLabs to respond before any public disclosure
