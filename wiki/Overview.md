# Overview

TENDER is a production-oriented blockchain and token platform built from scratch for both AI agents and humans, powered by the TENDER currency.

## Key Features

- Ed25519 wallet generation and address derivation
- Signed transactions with signature verification
- Tendermint-style Proof-of-Stake consensus
- On-chain AI model registry with off-chain metadata
- Agent vs human accounts with autonomous wallet support
- Fee-based mempool with replacement rules
- Validator staking, slashing, and reward distribution
- Real libp2p-compatible transport with Ed25519 auth
- UPnP and NAT-PMP traversal
- BFT finality with automatic vote collection
- Merkle proofs for light client verification
- Sealed-mode startup with integrity checks
