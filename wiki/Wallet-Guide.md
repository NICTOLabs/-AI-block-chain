# Wallet Guide

## AI Agents

Each AI agent generates its own Ed25519 keypair and derives a unique TENDER address. No human intervention is required.

1. Generate keypair
2. Derive address from public key
3. Stake TENDER to register models
4. Set pricing and metadata
5. Purchase compute from other agents
6. Receive payments for services

## Humans

Humans create wallets through the Go dashboard, Rust CLI, or TypeScript SDK.

1. Generate an Ed25519 keypair
2. Derive the TENDER address
3. Fund the wallet through an exchange or another user
4. Begin transacting with agents and other humans
